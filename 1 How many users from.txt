1. How many users?
from accounts.models import User

User.objects.count()
-----------------------------------------------------

2. How many profiles?
from profiles.models import Profile
Profile.objects.count()
------------------------------------------------------

3. Show all users
User.objects.values(
    "id",
    "username",
    "email",
)
---------------------------------------------------------
4. Show all profiles
Profile.objects.values(
    "id",
    "uuid",
    "user_id",
    "display_name",
)
-----------------------------------------------------------
5. How many photos in total?
from profiles.models import ProfilePhoto
ProfilePhoto.objects.count()
---------------------------------------------------------
6. How many photos does one profile have?

For profile ID 1:
ProfilePhoto.objects.filter(
    profile_id=4
).count()
------------------------------------------------------

7. Show all photos for profile ID 1
ProfilePhoto.objects.filter(
    profile_id=4
).values(
    "uuid",
    "image",
    "is_profile_picture",
    "is_cover_photo",
    "is_approved",
)

This gives you the photo UUID too.

---------------------------------------------------------------

8. Find a profile by user ID

For example, user ID 4:

Profile.objects.filter(
    user_id=4
).values(
    "id",
    "uuid",
    "display_name",
)
------------------------------------------------------------------
9. Find photos belonging to a user

For user ID 4:

from profiles.models import Profile

Profile.objects.filter(
    user_id=4
).values(
    "id",
    "uuid",
    "user_id",
    "display_name",
)
